### §2.2 Composite Score Formülleri

**Path A — Quality + Profitability binary intersection** (Li-Mohanram paterni):
```
F&V/P_signal = [F-Score top quintile binary] AND [V/P top quintile binary]
QMJ_signal   = [QMJ 4-dimension z-score top quintile]
Quality_long = F&V/P_signal AND QMJ_signal
```

**Path B — Profitability × Value continuous rank product** (Novy-Marx Fortune 500 paterni):
```
GP×V/P_rank = rank(GP/A) + rank(V/P)   # cross-sectional rank, ascending
Path_B_long = top 150 of GP×V/P_rank   # Fortune 500 spec replikasyon
```

**Path C — Value (adjusted HML)**:
```
adjusted_Bm = (Book_equity + R&D_capital_PI + 0.30 × SGA_capital_PI) / Market_equity
              # Lev-Sougiannis Knowledge + Peters-Taylor θ=0.30 partial allocation
Path_C_long = top quintile of adjusted_Bm
```

**Path D — Momentum overlay**:
```
UMD_long_only = top 30% of past-12-month return excluding past-1-month
                # Israel-Moskowitz long-only Q5 paterni
                # NOT: aylık-orijinal annual-uyarlama Q33 sensitivity test (§6 madde 4)
```

### §2.3 Forensic Filter

**Beneish M-Score** ([[factors/M_Score]]):
- Cutoff: `M-Score > -2.22` → suspect manipulator → REJECT
- Prior `.025` (sample-derived; large-cap kalibrasyon Q46 sensitivity test §6 madde 6)

### §2.4 Long Portfolio Construction

```
eligible_pool   = S&P 500 ∩ (NOT Beneish flagged)
candidate_long  = eligible_pool ∩ (Path_A ∪ Path_B ∪ Path_C ∪ Path_D)
final_long      = top 30-50 stocks of candidate_long, weighted by:
                  - capped VW (NYSE 80th percentile winsorize) baseline
                  - 7-theme balanced allocation
                  - GICS Level-1 max 25% concentration cap
```
